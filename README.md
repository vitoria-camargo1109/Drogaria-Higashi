## ⚕️ Farmácia Drogaria Higashi
Bem-vindo ao repositório do projeto Drogaria Higashi, uma aplicação web interativa voltada para a gestão e simulação de um sistema de drogaria, incluindo controle de fornecedores, produtos e atendimento.

Você pode acessar a versão ao vivo do projeto aqui:<a href="https://vitoria-camargo1109.github.io/Drogaria-Higashi/"> Drogaria Higashi</a>

## ✨ Funcionalidades

Gestão de Fornecedores: Visualização, cadastro e gerenciamento de fornecedores parceiros da drogaria.

Catálogo de Produtos: Consulta de medicamentos e produtos de higiene/saúde.

Interface Responsiva: Layout adaptado para diferentes tamanhos de tela (desktop e dispositivos móveis).

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias fundamentais para o desenvolvimento web front-end:

HTML5: Estruturação semântica das páginas.

CSS3: Estilização, design responsivo e identidade visual.

JavaScript: Dinamismo da interface e interatividade.

GitHub Pages: Hospedagem e implantação contínua da aplicação.
